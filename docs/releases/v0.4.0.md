# BlackForge 0.4.0 — Community Forge

BlackForge 0.4 turns the Arch/BlackArch package navigator into a safer,
reproducible toolkit manager and adds a public home for its documentation and
reviewed community collections.

## Highlights

- Audit outdated, vulnerable, unavailable, and keyring states without mixing
  them with upstream maintenance evidence.
- Create exact version locks, compare another machine, and export CycloneDX or
  SPDX SBOMs.
- Detect Btrfs/Snapper, request pre-transaction snapshots, and plan exact
  pacman-cache rollbacks without executing them.
- Browse and apply reviewed data-only community presets. Presets cannot contain
  commands, hooks, remote installers, credentials, or unknown packages.
- Opt in to AUR metadata discovery without downloading or executing a PKGBUILD.
- Generate portable maintenance dashboards and optional native Linux
  integration files.
- Use the new website, searchable wiki, and community preset contribution hub
  at <https://johnnypatty.github.io/blackforge/>.

## Install

```bash
git clone https://github.com/johnnypatty/blackforge.git
cd blackforge
bash install.sh
blackforge --version
```

Existing install-script users can update from the repository or use the
checksum-verified self-update flow after this release is published.

## Start here

```bash
blackforge audit
blackforge community list
blackforge community show network-observation
blackforge lock create lab.lock.json nmap amass
blackforge dashboard build blackforge-report.html --record
man blackforge
```

BlackForge remains unofficial and does not grant permission to use security
tools against third-party systems.
